# config

- `theme.js` — Chakra UI custom theme. Dark colour palette, border radii, shadows, semantic tokens, and responsive breakpoints. Built with `createSystem` + `mergeConfigs`.
- `settings.js` — App-wide constants: polling interval (30 s), opening hours (8 AM–8 PM), inactivity timeout, status threshold.
- `old/floorPlanZones.js` — Legacy hardcoded floor-plan clickable zones (position, shape, rotation, layer). Deprecated.
