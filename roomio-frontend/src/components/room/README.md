# Room

- `RoomStatusCard.jsx` — Room card with photo, status overlay, next reservation, and booking button.
- `RoomInfoPanel.jsx` — Metadata panel showing room name, capacity, and equipment icons (TV, whiteboard, computer).
- `Calendar.jsx` — Day-grouped vertical list of upcoming reservations with delete confirmation flow.
- `MeetingProgress.jsx` — SVG circular progress indicator showing elapsed and remaining meeting time.
