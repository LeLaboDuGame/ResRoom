# Admin

- `AdminTabs.jsx` — Tab container switching between the rooms, settings, and history views.
- `RoomsTab.jsx` — CRUD panel for creating, editing, and deleting rooms with photo upload.
- `SettingsTab.jsx` — Admin form for configuring day start/end hours and notification thresholds.
- `HistoryTab.jsx` — Filterable table of past reservations with inline deletion.
