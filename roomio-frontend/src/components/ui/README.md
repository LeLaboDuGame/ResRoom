# UI

- `StatusBadge.jsx` — Pill badge with colored dot and label for room status (free, starting soon, meeting, finishing soon).
- `ResRoomLogo.jsx` — ResRoom SVG logo image component.
- `LoadingSkeleton.jsx` — Animated pulse skeleton placeholder for text, circle, or card shapes.
- `FilterBar.jsx` — Filter controls for minimum capacity and equipment checkboxes (TV, whiteboard, PC).
- `EmptyState.jsx` — Centered empty-state placeholder with icon, title, and description.
- `Clock.jsx` — Live digital clock displaying HH:MM:SS, updated every second via the useClock hook.
